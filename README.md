IronhandedLayman's nixos configuration
--------------------------------------

# Summary

This is a store of my entire NixOS configuration for my main desktop, and soon
to spread out to my entire homelab, at which point I will have to move this to
another name, as nix-config by itself will no longer make sense.

# Usage

## Installation

* `nixos-install --flake https://github.com/ironhandedlayman/nix-config#<hostname>` will build the system represented. So far this is only one host, but I plan to expand that soon.
* [TODO] make this usable via `nixos-anywhere`

## Maintenance

* Pull repo
* Run `nix flake update` if you want to update packages.
* Change configuration files.
* If new files, make sure to `git add` in order to stage the relevant files (NixOS will see the changed local files but will ONLY look on the `git` stage for relevant files.`
* `nixos-rebuld switch --flake .#hokusai`
* If successful, commit and push files up.

# Architecture

## Files in repo:

* `hardware-configuration.nix` -- Hardware configuration of the first host... soon to break up into `<hostname>-hardware-configuration.nix`. Furthermore, this host's config file has been modified from the pregenerated file, and should be broken up into system-specific config related solely to hardware, and autogenerated content. 
* `flake.nix` -- Switchboard of the entire configuration, including all sources.
* `flake.lock` -- Refs for all inputs in `flake.nix`, only updated via `nix flake update`
* `configuration.nix` -- should be the set definition for all systems, with variations set in specific `<hostname>-configuration.nix` files as needed. 
* `<username>-home.nix` -- home-manager configuration for that particular user.
* `neovim.nix` -- neovim configuration based on the `nixvim` module.

# Troubleshooting

## MacOS notes (nix-darwin)

* Are you getting an error such as: `Could not find service "org.nixos.nix-daemon" in domain for system`
  * Maybe the nix daemon is not running, try `sudo launchctl load /Library/LaunchDaemons/org.nixos.nix-daemon.plist`
